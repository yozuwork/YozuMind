# YozuMind

React + Vite 繁體中文心智圖，介面統一使用 Bootstrap Icons。

## 開發

需要 Node.js 22.12 以上版本。

```sh
npm install
npm run dev
```

## 建置與部署

```sh
npm run build
npm run preview
npm run deploy
```

`npm run deploy` 會先建置，再將 dist 發佈到 gh-pages 分支。GitHub Settings → Pages 選擇 Deploy from a branch、gh-pages、/ (root)。

網站：https://yozuwork.github.io/YozuMind/

Windows PowerShell 若限制 npm 指令碼，可使用 npm.cmd。

## 功能與資料

保留多張心智圖、搜尋、複製、節點編輯、拖曳、分支顏色、收合、雙向排列、縮放、復原與重做。

左側欄的每張心智圖以便利貼圖示顯示，點上方標題旁的便利貼可換顏色（預設跟隨主題）。「新增資料夾」可建立資料夾，把心智圖拖進資料夾，或從「⋯」選單選「移到資料夾」來整理；拖到外層空白處即可移出。資料夾也能放進其他資料夾（拖曳，或用資料夾「⋯」選單的「新增子資料夾」「移到資料夾」），並可在「更換顏色」改變資料夾圖示顏色。刪除資料夾時，裡面的心智圖與子資料夾會移到上一層。資料夾會一起匯出與匯入。

畫布左側的工具列提供 Milanote 風格卡片：便利貼筆記、連結、待辦清單、欄位、心智圖、資料夾，以及關聯線工具。便利貼預設為白色（深色主題為深色卡片），可選多種顏色；筆記內以「[ ] 」開頭的行會變成可勾選的待辦，也能用筆記上方的「加入待辦」按鈕新增，編輯時在待辦行按 Enter 會接續下一項。用 ``` 包住的內容（或筆記上方的「插入程式碼」按鈕）會顯示成有行號與語法上色的深色程式碼區塊，開頭可註明語言（例如 ```js），右上角可一鍵複製，編輯時按 Tab 會縮排。圖片、卡片與塗鴉共用堆疊順序，新增或剛移動的物件會在最上層。資料夾可收納筆記，點選後再點一次即可展開或收合。欄位與資料夾標題列的圖片按鈕可加入圖片，畫布上的圖片也能直接拖進欄位或資料夾。「獨立頁面」工具（參考 Milanote 的 Board）會建立一張資料夾圖示的頁面卡片，連到一張獨立的空白畫布：點選後再點一次或雙擊即可進入，上方的路徑可回到上一層。頁面卡片可拖曳右下角自由調整大小、切換外框、更換資料夾顏色，也能拖進欄位或筆記內嵌。移除頁面卡片時，頁面本身會移到側欄而不會被刪除。心智圖節點也能有自己的獨立頁面：選取節點後按工具列的資料夾按鈕建立並進入，之後節點右上角會出現資料夾標記，雙擊即可進入。按「檢視內容」（頁面卡片上方也有）會在右側彈出側邊欄顯示並編輯該頁面，標題列可切換滿版、在主畫面開啟或關閉（Esc），兩邊的修改會即時同步。欄位與筆記都可以收合：欄位標題列與筆記右上角的箭頭，或卡片上方的收合按鈕。筆記與欄位選取後也可拖曳右下角調整寬度與高度（高度為最小值，內容多時會自動撐開）。

「心智圖」工具會在同一張圖板上再新增一棵心智圖，拖曳中心主題即可移動整棵樹；任何中心主題（包含原本的）都能用 Delete 刪除整棵樹，圖板可以完全清空後再用工具新增。點一下會在畫面中央新增，也可以拖曳到畫布或欄位內；點選後再點一次（或雙擊）即可編輯，Delete 刪除，可拖進或拖出欄位，也能用關聯線連接。

「塗鴉」工具仿照 Whimsical：開啟後左上會出現畫筆面板，可切換筆（P）、螢光筆（H）、形狀（S）、橡皮擦（E）與套索選取（L），並選擇粗細與顏色。「形狀」仿照剪取工具，可在圖片或畫布上拖曳畫出矩形、橢圓、直線與箭頭（按住 Shift 畫正方形／正圓或鎖定 45° 角），外框使用面板顏色，並可選擇填滿顏色。套索圈選後可拖曳移動、換色、換粗細或按 Delete 刪除；按 Esc 或「完成」離開塗鴉模式，塗鴉會留在圖板上並一起儲存與匯出。

關聯線仿照 Whimsical：滑鼠移到節點、卡片或圖片上會出現四個連接點，按住拖到目標即可連線，靠近目標的邊會自動吸附。也可以按上方的關聯線按鈕，選擇轉折線、直線或曲線，再從物件拖到目標，或依序點選兩個物件。點選線條可調整文字、顏色、實線／虛線／粗線、箭頭方向與線型，拖曳兩端圓點可改接到其他物件。

介面預設使用 Milanote 淺色色系，右上角的月亮按鈕可切換為深色色系，選擇會記在此瀏覽器。

資料儲存在瀏覽器 localStorage，沿用 yozu-mindmap-v1 格式並相容舊圖示。GitHub Pages 沒有帳號同步，分享網址不會分享本機心智圖。

src/App.jsx 負責 React 介面；src/mindmap.js 隔離原畫布與儲存引擎；src/styles.css 保留原介面與響應式樣式。原始 HTML 留作參考。

## 存檔與還原

側欄的「匯出目前心智圖」下載單張 JSON 存檔；「備份全部心智圖」下載完整備份。「匯入 JSON 存檔」可還原上述檔案，並支援原版資料陣列與單張心智圖 JSON。匯入會新增副本，不覆蓋現有資料，保留名稱、圖示、排列方向、節點、顏色與收合狀態。

檔案上限 25 MB、每批 100 張心智圖、共 10,000 個節點與 100 層。格式錯誤的整批匯入不會寫入資料。若瀏覽器空間不足會顯示暫存失敗提示，請匯出備份。清除瀏覽器網站資料會移除暫存，可使用 JSON 存檔還原。

## 圖片與關聯線

複製圖片後在畫布按 Ctrl+V（Mac 為 Cmd+V），或使用上方圖片按鈕選檔。圖片可自由拖曳，選取後拖動四角可等比例縮放。圖片會轉為最長邊 1600 像素的 WebP，GIF 會以靜態圖片呈現。

按上方關聯線按鈕，再依序點選起點與終點（節點或圖片），即可建立有方向的虛線箭頭。拖曳圖片或重新排列節點時，關聯線會跟隨端點。點選圖片或線後按 Delete，或使用畫布中的刪除按鈕；Esc 可取消選取或連線。圖片和關聯線支援復原／重做，並包含於瀏覽器暫存及 JSON 存檔。

存檔格式檢查：`node --test src/files.test.js`。
